Set up Inference Bridge

  1. Enable the extension. In Settings → Apps → Safari → Extensions → Inference Bridge, turn on Allow Extension.
  2. Allow a website. In Safari, open a site that uses Inference Bridge. Tap the Page Menu beside the address bar, choose Inference Bridge, and allow access to that site. Reload the page.

Safari’s permission lets Bridge run on the site. The site also needs your approval in Bridge to make AI requests.
