Set up Inference Bridge

  1. Enable the extension. In Settings → Apps → Safari → Extensions → Inference Bridge, turn on Allow Extension.
  2. Choose website access. To use Bridge across sites, choose Other Websites → Allow under Permissions in the same Settings screen. To allow one site, open it in Safari and choose Page Menu → Inference Bridge. Reload the page after allowing access.
  3. Add a provider API key. In Safari, open Page Menu → Inference Bridge to open extension settings. Under Providers, select a provider, paste the key from your provider account into API key, and tap Save. If prompted, choose a model and save again.

Safari’s permission lets Bridge run on the site. The site also needs your approval in Bridge to make AI requests.
